# Security policy

FastGem is an alpha developer preview. Do not expose the current runtime to the public internet without adding authentication, HTTPS, rate limiting, secret management, and durable production storage.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Contact the repository maintainer privately through the GitHub security contact or direct account contact and include:

- A concise description of the issue.
- The affected endpoint, file, or version.
- Reproduction steps that do not include secrets or private data.
- The potential impact.

Please allow time for investigation and remediation before public disclosure.

## Sensitive data

Never post Gemini API keys, access tokens, private prompts, logs containing secrets, or customer data in issues, pull requests, or screenshots. If a key is exposed, revoke it immediately and replace it.
